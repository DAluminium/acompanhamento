# Acompanhamento

Módulo de medição de vãos da D'Aluminium: uma ficha por esquadria, montada a
partir do PDF de medição do SmartCEM anexado na obra (Gerenciamento de Obra),
com medidas, condição do vão, fotos, áudios, visitas e os PDFs para o cliente.

- Produção: https://daluminium.github.io/acompanhamento/
- Abre pelo portal: https://daluminium.github.io/portal/
- Versão de teste: `teste/acompanhamento.html` no repositório `teste`.

`croquis-lista.json` é só a lista dos códigos dos croquis do SmartCEM. As
imagens ficam na nuvem privada da empresa, nunca neste repositório (que é
público).
